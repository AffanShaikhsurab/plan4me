# Security Policy

## Supported versions

This project is under active development. Security fixes are applied on the
default branch (`master`) as needed.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead:

1. Use [GitHub Security Advisories](https://github.com/AffanShaikhsurab/plan4me/security/advisories/new) if available on the repo, **or**
2. Email the maintainer privately via the contact listed on the GitHub profile.

Include:

- A description of the issue and its impact
- Steps to reproduce (PoC if possible)
- Affected versions / commit if known

We will acknowledge receipt as soon as practical and work on a fix before any
public disclosure.

## Non-security bugs

Use normal GitHub issues for crashes, incorrect research output, docs gaps, and
feature requests.
